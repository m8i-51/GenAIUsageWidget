## Name

GenAI Usage

## Description

<!-- description:start -->
GenAI Usage puts your AI coding usage limits on Stream Deck keys. Each key shows one limit, such as Claude's 5-hour window or Codex's weekly cap, as a water level that turns orange at 45% and red at 70%. Press a key to see when that limit resets.

Works with Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Antigravity, Windsurf, Kiro and z.ai.

Actions
- Usage Limit: pick a provider and one of its limits. Model-specific caps are listed by name.
- Closest Limit: always shows whichever limit is nearest its cap across the providers you tick.

On every key
- Press to show the time until reset (it switches back after 10 seconds).
- Hold to refresh right away.
- If a provider can't be reached, the key keeps the last good numbers and marks them with a clock.

Requirements
- Windows 10 or later and Stream Deck 6.5 or later.
- Sign in to each tool on this PC first (for example the Claude Code or Codex CLI, or the Cursor app). The plugin reads those existing sign-ins.
- Antigravity and Copilot on Windows need Python on PATH.
- z.ai keys need the free GenAIUsageWidget app running.

When GenAIUsageWidget is running, keys reuse its numbers, so providers are never polled twice. No analytics; sign-ins are only sent to each provider's own API. Open source (MIT).
